# V2 — A股一进二 Top1 / Top2 优化版

本版本从 `v1-stable` 独立分支创建，专门优化“首板 → 次日二板”的 **Top1 / Top2 日内排序准确率**。

## 与 V1 的关系

- V1 逻辑与参数完全不修改。
- V2 单独训练、单独回测、单独输出 `model_v2.json`。
- V2 当前只做历史研究；只有严格 OOS 明确优于 V1 后，才考虑制作独立的 V2 日常扫描器。
- 后续任何 V2.1 / V3 都应从明确版本基线再开独立分支，不覆盖 V2。

## V2 当前策略思路

V2 不简单地把 V1 的全部参数重新调一遍，而是做三层调整：

1. **增加首板专属结构特征**：换手、量能、前一日状态、首板前 5/10/20 日涨停历史、距上次涨停间隔、趋势位置、市场连板生态等。
2. **引入 V1 分数作为基线信号**：避免优化后完全丢失 V1 已经验证过的有效信息。
3. **按“日内排名”融合 V1 与 V2**：因为实际只需要每天选 Top1 / Top2，所以最终优化目标直接使用开发区间的 Top1 / Top2 precision，而不是追求跨日期的概率校准。

## 回测口径

- 数据源：新浪财经日线。
- 股票范围：沪深主板，排除科创板、创业板、北交所、ST/*ST/退市。
- 历史窗口：2026-03-20 至 2026-09-18。
- 开发区间：2026-06-01 至 2026-07-08。
- 严格 OOS：2026-07-09 至 2026-09-18。
- 目标函数：0.6 × Top1 precision + 0.4 × Top2 precision。
- Top6 仅保留作为辅助观察，不参与 V2 参数选择。

## 重要限制

这个版本和 V1 一样使用当前可检索证券列表构建历史样本，因此存在潜在的幸存者偏差；同时“涨停”由日线涨幅规则近似重建，并非交易所逐笔/分钟级的真实涨停事件。

## 下一步判断标准

V2 是否值得继续，不看开发区间单点提升，而主要看严格 OOS：

- Top1 precision 是否高于 V1；
- Top2 precision 是否高于 V1；
- Top1 + Top2 两个位置的综合 precision 是否高于 V1；
- 同时不能以大幅减少有效交易日为代价换取表面精度提升。

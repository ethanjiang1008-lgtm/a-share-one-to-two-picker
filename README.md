# A股首板一进二概率预测系统

独立项目：用于分析沪深主板首板股票次日晋级二板的概率。

本仓库与 seven-factor-stock-picker、short-term-up-probability-picker 以及任何“一夜持股”策略完全独立。

## V1 基线

当前 V1 固定使用已经完成样本外验证的第二轮日K封板结构代理模型。

- 回测区间：2025-10-16 ～ 2026-09-18
- 首板事件：8,662
- 时间切分：2026-07-08
- 训练样本：6,098
- 测试样本：2,564
- 基线 Top1：37.25%
- V1 Top1：41.18%
- 提升：+3.92 个百分点

41.18% 是当前已经验证的 V1 参考结果；尚未完成验证的 5 分钟封板结构不加入 V1。

## 市场范围

只分析上海/深圳主板：600、601、603、605、000、001、002、003。

排除创业板 300/301、科创板 688/689、北交所、ST/*ST、退市股。

## 数据源

V1 行情数据统一使用新浪财经公开行情接口。

V1 不依赖东方财富 5 分钟接口。

## 当前运行模式

V1 按**实际运行时刻**进行预测，不要求必须等收盘。

- **09:25～15:05 盘中运行**：读取新浪实时行情；把当前价格、当日最高/最低、截至当前成交量/成交额等合成为“截至运行时刻的当日K线”，与此前完整日K拼接后计算 V1 特征。
- **15:05 后运行**：使用当日已经完成的正式日K，得到收盘版预测。
- **周末/休市日运行**：使用最近一个已完成交易日，预测下一个实际交易日。
- **09:25 前运行**：不伪造“今天首板”，页面仅返回开盘前状态。

因此同一个交易日可以在 09:35、10:30、14:30、15:10 分别运行；每次都会以该时刻的数据重新计算排序。V1 的概率公式没有因为盘中运行而改变。

## TopK 统计与滚动验证

V1 当前仓库里保存的历史验证基准只有 **Top1=41.18%**。原始 2,564 条测试样本的逐股排名文件没有随代码仓库保存，因此不能在不引入新数据的情况下声称 Top3/Top6/Top10 的历史回测数值。

现在系统会从首次正式运行开始自动做“下一交易日滚动实测”：
- Top1 / Top3 / Top6 / Top10 的股票级晋级率
- 每天 TopK 至少命中 1 只的天数占比
- 自动保存到 reports/evaluation/topk_summary.json 和 daily_topk_validation.csv
- Excel 的“历史TopK”页签同步展示

因此后续积累的真实运行样本，可以直接观察 TopK 作为初筛器的实际表现；该统计不修改 V1 模型参数。

## Excel 复盘文件

系统只维护 **一个长期 Excel 工作簿**：
- `reports/excel/a_share_one_to_two_review.xlsx`
- `docs/downloads/latest.xlsx` 是网页侧对同一份最新工作簿的同步副本
- 每次运行都会重新整理全部历史日报，因此不同交易日持续累积在同一个文件中。
- **同一分析日重复运行**时，只保留该日期最新一次预测结果，不重复堆积。
- Excel 页签包括“每日预测 / 复盘验证 / 历史TopK / 证据”。

“复盘验证”只在预测对应的下一个实际交易日已经发生后填写。系统会验证 Top10 中每只股票的次日开盘、最高、收盘表现以及是否晋级二板；其中“是否二板”按次日收盘后的实际二连板结果确认。竞价阶段数据暂不虚构，后续如接入可靠竞价数据源再补充。

## 涨停原因证据层

从当前版本开始，每次日终扫描会对首板候选补充独立的事件证据层，**不参与 V1 概率计算**。

证据优先级与用途：
- **巨潮资讯**：上市公司当日公告；作为最重要的直接事件证据。
- **东方财富个股新闻**：当日个股相关新闻，用于补充公告之外的市场信息。
- **财联社快讯**：全市场当日快讯；只有标题或正文明确出现股票代码/简称时，才归为该股直接证据。
- **同花顺热点题材归因**：当日市场题材标签，仅作为“市场如何归因”的线索，不单独视为事实证据。

网页会把结果区分为：
- **已验证**：找到当日直接相关公告/新闻/快讯。
- **仅背景**：只有前一交易日前后的相关信息，不能证明当天直接催化。
- **仅题材标签**：存在当日题材归因，但没有找到可验证的直接事件。
- **无直接证据**：不编造涨停原因。

每只首板股还会展示：
- 当日涨停原因详细说明
- 事件证据标题、来源、日期及可点击链接
- 原因类型（业绩、订单、合作、政策、产品技术、并购重组等）
- 原因持续性：高 / 中 / 低 / 未知
- V1 模型实际入模因子的正负贡献
- 主要风险

这样网页的逻辑是：
**涨停事实 → 事件证据 → 市场题材归因 → 首板结构 → V1 概率 → 概率依据 → 风险**。

V1 概率模型保持冻结，不因“新闻/公告原因分析”而重新训练；任何将事件因子加入概率模型的改动，都必须重新做时间序列样本外验证。


## 日期口径

系统不使用“自然日 + 1”作为预测日期，而使用“下一个 A 股实际交易日”。

例如：
- 周六/周日手动运行：自动使用最近一个已有行情的交易日作为**分析日期**，预测下一个实际交易日。
- 周五运行：预测下周一；若周一休市，则继续顺延。
- 节假日前最后交易日运行：预测节后第一个实际交易日。

网页会同时显示：
**分析日期** = 本次实际用于识别首板和计算 V1 的交易日；
**预测日期** = 下一个实际 A 股交易日。

2026 年休市日配置单独保存在 `config/trading_calendar.json`；周末自动排除。2026 年上交所与深交所公布的休市安排一致，例如 2026 年 9 月 25～27 日休市、9 月 28 日恢复交易。

## 信息截止与重复运行

每次运行都会记录本次任务的**实际信息截止时间**（北京时间）。同一个分析日可以重复运行多次：

- **V1 原始公式固定，但输入数据按运行时刻更新**；盘中重复运行会重新计算概率并重新排序。
- 新闻、公告、政策与题材信息会根据新的截止时间重新检索。
- 每次运行都会保存独立 JSON 快照，文件名包含信息截止时间，不会覆盖历史快照。
- 网页 `docs/data/latest.json` 始终展示最新一次运行结果。
- 同一交易日的长期 Excel 台账只保留该日期最新一次预测；历史时间点仍可从 cutoff 快照追溯。


## 每日运行时间

工作日可以在任意需要的交易时段手动触发。盘中运行得到的是**截至该运行时刻**的动态预测，不代表当日最终结果；收盘后再运行会自然切换到完整日K版本。

GitHub Actions 的自动任务仍保留在约 15:10 北京时间运行，用于生成每日收盘版并完成次日复盘验证。


## V2 多级连板晋级预测（独立系统）

V2 与 V1 完全独立，**不修改 V1 参数、V1 模型文件或 V1 的 41.18% 参考基准**。

V2 当前按板级分别建模：
- 1→2：首板次日晋级二板
- 2→3：二板次日晋级三板
- 3→4：三板次日晋级四板
- 4→5：四板次日晋级五板
- 5→6：五板次日晋级六板
- 6→7+：六板及以上次日继续晋级

每一级使用自己的历史样本、自己的 Logistic 模型和时间序列样本外区间（训练截止 2026-07-08，样本外从 2026-07-09 开始）。

### V2 当前优化

在首轮真实回测后，V2 直接在原系统上继续迭代，不另建版本。当前优化包括：

1. **修正K线结构特征**
   - 下影线改为标准的 min(open, close) - low 计算，不再把“开盘到最低价”误当作下影线。
   - 增加实体占比、上影线占比、收盘在日内振幅中的位置等封板质量特征。
   - 增加前一交易日的开盘涨幅、振幅、成交量强弱、收盘位置等滞后结构。

2. **增加连板惯性特征**
   - 近5/10个交易日历史涨停次数
   - 距离上一次涨停的交易日数
   - 20/60/120日相对高位
   - 20日均线斜率
   - 当日/前一日成交量变化

3. **增加板级市场环境**
   - 当前相同板级股票数量
   - 当前更高板级数量
   - 前一交易日相同板级与更高板级数量
   - 前一交易日“同板级→下一板级”的市场接力率

4. **参数采用时间序列验证选择**
   - 仅对样本相对充足的 1→2、2→3、3→4 做扩展窗口验证。
   - 在不打乱时间顺序的前提下选择 Logistic 正则强度和类别权重。
   - 4→5、5→6 等小样本档位不进行激进调参，避免把有限历史样本过拟合。

历史 TopK 仍然按**每个预测日分别排序**后统计，而不是把整个样本外区间混在一起排序。

V2 每次模型运行同时输出：
- config/models_v2.json
- reports/multi_tier_v2_backtest.json
- reports/multi_tier_v2_samples.csv
- docs/data/multi_tier_latest.json

V2 工作流：V2 多级连板晋级预测（.github/workflows/multi-tier-v2.yml）。

除手动运行和工作日定时运行外，V2 在上述模型代码变更后也会自动触发一次完整回测与网页更新，避免优化后的代码没有经过真实数据验证。

注意：V2 当前仍属于样本外研究基线。高板级别的历史样本数量明显较少，尤其 6→7+，因此暂不把极小样本结果当作稳定模型结论。当前历史数据基于现有主板股票池，仍存在当前股票池回看历史的生存者偏差，需要后续接入历史成分股数据后再进一步校正。

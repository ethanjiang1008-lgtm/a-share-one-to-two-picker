# A股首板一进二概率预测系统

独立项目：用于分析沪深主板首板股票次日晋级二板的概率。

本仓库与 seven-factor-stock-picker、short-term-up-probability-picker 以及任何“一夜持股”策略完全独立。

## V1 基线

当前 V1 固定使用已经完成样本外验证的第二轮日K封板结构代理模型。

- 回测区间：2025-10-16 ～ 2026-09-18
- 首板事件：8,662
- 时间切分：2026-07-08
- 训练样本：6,098
- 测试样本：2,564
- 基线 Top1：37.25%
- V1 Top1：41.18%
- 提升：+3.92 个百分点

41.18% 是当前已经验证的 V1 参考结果；尚未完成验证的 5 分钟封板结构不加入 V1。

## 市场范围

只分析上海/深圳主板：600、601、603、605、000、001、002、003。

排除创业板 300/301、科创板 688/689、北交所、ST/*ST、退市股。

## 数据源

V1 行情数据统一使用新浪财经公开行情接口。

V1 不依赖东方财富 5 分钟接口。

## 当前运行模式

V1 采用收盘后快速预测：获取当天主板行情快照 -> 找出涨停股 -> 判断首板 -> 对首板股获取最近日K -> 计算 V1 特征 -> 输出次日二板概率排序。

后续再增加 14:30 尾盘模式和真实盘中封板结构。

## TopK 统计与滚动验证

V1 当前仓库里保存的历史验证基准只有 **Top1=41.18%**。原始 2,564 条测试样本的逐股排名文件没有随代码仓库保存，因此不能在不引入新数据的情况下声称 Top3/Top6/Top10 的历史回测数值。

现在系统会从首次正式运行开始自动做“下一交易日滚动实测”：
- Top1 / Top3 / Top6 / Top10 的股票级晋级率
- 每天 TopK 至少命中 1 只的天数占比
- 自动保存到 reports/evaluation/topk_summary.json 和 daily_topk_validation.csv
- Excel 的“历史TopK”页签同步展示

因此后续积累的真实运行样本，可以直接观察 TopK 作为初筛器的实际表现；该统计不修改 V1 模型参数。

## 涨停原因证据层

从当前版本开始，每次日终扫描会对首板候选补充独立的事件证据层，**不参与 V1 概率计算**。

证据优先级与用途：
- **巨潮资讯**：上市公司当日公告；作为最重要的直接事件证据。
- **东方财富个股新闻**：当日个股相关新闻，用于补充公告之外的市场信息。
- **财联社快讯**：全市场当日快讯；只有标题或正文明确出现股票代码/简称时，才归为该股直接证据。
- **同花顺热点题材归因**：当日市场题材标签，仅作为“市场如何归因”的线索，不单独视为事实证据。

网页会把结果区分为：
- **已验证**：找到当日直接相关公告/新闻/快讯。
- **仅背景**：只有前一交易日前后的相关信息，不能证明当天直接催化。
- **仅题材标签**：存在当日题材归因，但没有找到可验证的直接事件。
- **无直接证据**：不编造涨停原因。

每只首板股还会展示：
- 当日涨停原因详细说明
- 事件证据标题、来源、日期及可点击链接
- 原因类型（业绩、订单、合作、政策、产品技术、并购重组等）
- 原因持续性：高 / 中 / 低 / 未知
- V1 模型实际入模因子的正负贡献
- 主要风险

这样网页的逻辑是：
**涨停事实 → 事件证据 → 市场题材归因 → 首板结构 → V1 概率 → 概率依据 → 风险**。

V1 概率模型保持冻结，不因“新闻/公告原因分析”而重新训练；任何将事件因子加入概率模型的改动，都必须重新做时间序列样本外验证。


## 日期口径

系统不使用“自然日 + 1”作为预测日期，而使用“下一个 A 股实际交易日”。

例如：
- 周六/周日手动运行：自动使用最近一个已有行情的交易日作为**分析日期**，预测下一个实际交易日。
- 周五运行：预测下周一；若周一休市，则继续顺延。
- 节假日前最后交易日运行：预测节后第一个实际交易日。

网页会同时显示：
**分析日期** = 本次实际用于识别首板和计算 V1 的交易日；
**预测日期** = 下一个实际 A 股交易日。

2026 年休市日配置单独保存在 `config/trading_calendar.json`；周末自动排除。2026 年上交所与深交所公布的休市安排一致，例如 2026 年 9 月 25～27 日休市、9 月 28 日恢复交易。

## 信息截止与重复运行

每次运行都会记录本次任务的**信息截止时间**（北京时间）。同一个分析日期可以重复运行多次：

- V1 原始概率保持一致，避免新消息污染已验证的模型结果。
- 新闻、公告、政策与题材信息会根据新的截止时间重新检索。
- 新增的分析日收盘后信息会单独展示为“信息变化”。
- 每次运行都会保存独立 JSON 快照，文件名包含信息截止时间，不会覆盖历史版本。
- 网页 `docs/data/latest.json` 始终展示最新一次运行结果。

因此，周六运行和周日晚运行得到不同的“综合判断”是正常的；差异来自两次运行之间新增的信息，而不是 V1 模型参数变化。
